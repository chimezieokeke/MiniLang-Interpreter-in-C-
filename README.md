# MiniLang Interpreter

A simple interpreter for the MiniLang toy language demonstrating key programming language concepts.

## Features

- Lexical and dynamic scoping
- Subprograms (functions) with parameters
- Nested scopes and closures
- Basic expression evaluation


install c++ extension 


run in cmd line:

g++ -std=c++17 MiniProg.cpp -o minilang
./minilang
